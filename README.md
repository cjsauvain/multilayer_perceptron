# Multi-Layer Perceptron

From-scratch (NumPy) implementation of a multilayer perceptron (MLP) trained with
gradient descent backpropagation, applied to breast cancer diagnosis on the
**Wisconsin Diagnostic Breast Cancer (WDBC)** dataset. The project provides a full
command-line pipeline: dataset splitting, feature analysis/selection, training and
prediction.

## Dataset

The WDBC dataset (`datasets/data.csv`) contains 569 samples, each described by an ID,
a diagnosis (`M` = malignant, `B` = benign) and 30 numeric features (radius, texture,
perimeter, area, symmetry, etc., each declined as `_mean`, `_se` and `_worst`). The
file has no header; column names are defined in
[src/constants.py](src/constants.py) and applied automatically on load
(`load_dataset` detects both formats, with or without a header).

## Usage

### 1. Splitting the dataset

Splits `data.csv` into a training set and a validation set, preserving the
proportion of each class (`B`/`M`) in each split. The ratio must be strictly
between 0 and 1. The `ID` column is dropped. `datasets/data.csv` stays in git;
the two generated CSV files are gitignored.

```bash
python mlp.py split-dataset datasets/data.csv \
    --train-ratio 0.8 \
    --training-dataset datasets/dataset_training.csv \
    --validation-dataset datasets/dataset_validation.csv \
    --seed 42
```

### 2. Feature analysis

`feature_analysis.py` shows how the columns relate to the diagnosis and to
each other.

```bash
python feature_analysis.py datasets/data.csv feature-selection
```

The command prints three tables:

- the absolute correlation of every feature with `diagnosis`, strongest first;
- pairs above 0.9 among the features already correlated at least 0.3 with
  `diagnosis`, each pair once;
- a compact subset: features whose absolute correlation with `diagnosis` is at
  least 0.3, walked from the strongest link to the weakest, dropping a feature
  when it correlates above 0.9 with one already kept.

Individual visualization of each feature (boxplot or scatter plot, scatter plot
by default):

```bash
python feature_analysis.py datasets/data.csv feature-visualization --visualization-mode boxplot
```

### 3. Model configuration

Before training, copy the default architecture and edit that copy if needed:

```bash
cp model.example.json model.json
```

[model.example.json](model.example.json) is the network shipped with the project:
two hidden layers and a 2-neuron output (`[256, 64, 2]`), using all 30 WDBC
features. `train` reads `model.json` and validates it against
[model.schema.json](model.schema.json). If `layers` is omitted, the program uses
`[24, 24, 2]`.

```json
{
    "layers": [256, 64, 2],
    "activation": "relu",
    "weights_initializer": "HeNormal",
    "normalization": {
        "mode": "z-score"
    }
}
```

The `features` array in the file lists all 30 columns. It is omitted above.

- `layers`: number of neurons per hidden layer, the last value being the output
  layer (2 neurons: `B`/`M` probabilities). The output layer always uses `softmax`
  activation and `GlorotNormal` init, regardless of the settings below.
- `activation`: activation function for the hidden layers (`relu` or `sigmoid`).
- `features`: subset of dataset columns to use as input.
- `weights_initializer`: hidden layers initialization (`HeNormal` or `GlorotNormal`).
- `normalization.mode`: `z-score` or `min-max`.

Training computes `means` and `stds` (or `mins` and `maxs`) on the training set
and writes them to `model.json` before the fit. The example file only stores
the normalization mode.

### 4. Training

```bash
python mlp.py train datasets/dataset_training.csv datasets/dataset_validation.csv \
    --model-path model.json \
    --params-path params.npz \
    --learning-rate 0.1 \
    --epochs 10000 \
    --patience 20 \
    --seed 42
```

`--patience` defaults to 20. `--seed` defaults to unset; pass one when the run
must be reproducible. `--disable-epochs-metrics` shows a progress bar instead
of the per-epoch log. `--disable-visualization` skips the plots shown after
training.

Each epoch shuffles the training set and updates the weights on mini-batches of
32 samples. Early stopping watches the validation loss and restores the weights
of the best epoch. The end summary describes that restored model. Normalization
statistics are written to `model.json` before the fit. Weights and biases are
saved to `params.npz` afterwards. The plots show training and validation curves
for loss, accuracy, precision, recall and F1-score.

### 5. Prediction

```bash
python mlp.py predict datasets/dataset_validation.csv \
    --model-path model.json \
    --params-path params.npz \
    --display-accuracy \
    --output-file predictions/dataset_predict.csv
```

Predictions (`B`/`M`) are written to the output file. When `diagnosis` is
present and complete, the command prints the binary cross-entropy.
`--display-accuracy` also prints the accuracy.

## Technical details

- **Forward/Backward**: hand-written NumPy implementation (no deep learning
  framework), layer by layer ([src/model/layer.py](src/model/layer.py)).
  The output layer is softmax. Hidden layers use ReLU or sigmoid.
- **Optimization**: gradient descent on mini-batches of 32
  ([src/constants.py](src/constants.py)).
- **Loss**: binary cross-entropy ([src/model/loss.py](src/model/loss.py)),
  also printed by `predict` when the dataset contains the diagnosis.
- **Metrics**: accuracy, precision, recall and F1-score, computed every epoch
  on train and validation ([src/model/metrics.py](src/model/metrics.py)).
  The positive class is `M`. The same five metrics are plotted for both sets
  at the end of training.
- **Early stopping**: training stops if the validation loss does not improve
  for `--patience` consecutive epochs (default 20). The weights of the best
  validation loss are restored, and the logged history is cut back to that epoch.
- **Normalization**: z-score or min-max, fit on the training set and reapplied
  with the same statistics to the validation set and at prediction time.
- **Weight initialization**: He Normal or Glorot Normal for the hidden layers.
  The output layer always uses Glorot Normal.
