# multilayer_perceptron

From-scratch (NumPy) implementation of a multilayer perceptron (MLP) trained with
gradient descent backpropagation, applied to breast cancer diagnosis on the
**Wisconsin Diagnostic Breast Cancer (WDBC)** dataset. The project provides a full
command-line pipeline: dataset splitting, feature analysis/selection, training and
prediction.

## Dataset

The WDBC dataset (`datasets/data.csv`) contains 569 samples, each described by an ID,
a diagnosis (`M` = malignant, `B` = benign) and 30 numeric features (radius, texture,
perimeter, area, symmetry, etc., each declined as `_mean`, `_se` and `_worst`). The
file has no header; column names are defined in
[src/constants.py](src/constants.py) and applied automatically on load
(`load_dataset` detects both formats, with or without a header).

## Usage

### 1. Splitting the dataset

Splits `data.csv` into a training set and a validation set, preserving the
proportion of each class (`B`/`M`) in each split.

```bash
python mlp.py split-dataset datasets/data.csv \
    --train-ratio 0.8 \
    --training-dataset datasets/dataset_training.csv \
    --validation-dataset datasets/dataset_validation.csv \
    --seed 42
```

### 2. Feature analysis

`feature_analysis.py` helps choose which features to feed into the model.

Automatic selection of the most relevant features (correlation with diagnosis ≥ 0.5,
then pruning of correlated pairs ≥ 0.7):

```bash
python feature_analysis.py datasets/data.csv feature-selection --features-number 4
```

Individual visualization of each feature (boxplot or scatter plot):

```bash
python feature_analysis.py datasets/data.csv feature-visualization --visualization-mode boxplot
```

### 3. Model configuration

Before training, the network architecture must be described in a JSON file
(`model.json` by default), validated against [model.schema.json](model.schema.json):

```json
{
    "layers": [16, 16, 2],
    "activation": "relu",
    "features": [
        "perimeter_worst",
        "compactness_worst",
        "concavity_worst",
        "concave_points_worst"
    ],
    "weights_initializer": "HeNormal",
    "normalization": {
        "mode": "z-score"
    }
}
```

- `layers`: number of neurons per hidden layer, the last value being the output
  layer (2 neurons: `B`/`M` probabilities). The output layer always uses `softmax`
  activation and `GlorotNormal` init, regardless of the settings below.
- `activation`: activation function for the hidden layers (`relu` or `sigmoid`).
- `features`: subset of dataset columns to use as input.
- `weights_initializer`: hidden layers initialization (`HeNormal` or `GlorotNormal`).
- `normalization.mode`: `z-score` or `min-max`.

The `means`/`stds` (or `mins`/`maxs`) fields are computed and written back to this
file automatically at the end of training.

### 4. Training

```bash
python mlp.py train datasets/dataset_training.csv datasets/dataset_validation.csv \
    --model-path model.json \
    --params-path params.npz \
    --learning-rate 0.1 \
    --epochs 10000 \
    --patience 5 \
    --seed 42
```

Useful options: `--disable-epochs-metrics` (shows a progress bar instead of
per-epoch details), `--disable-visualization` (skips the plots shown after
training).

Training uses early stopping based on the validation loss (`--patience` epochs
without improvement), restores the best weights found, then saves:
- weights/biases to `params.npz`;
- architecture, features and normalization parameters to `model.json`.

### 5. Prediction

```bash
python mlp.py predict datasets/dataset_validation.csv \
    --model-path model.json \
    --params-path params.npz \
    --display-accuracy \
    --output-file predictions/dataset_predict.csv
```

Predictions (`B`/`M`) are written to the output file. `--display-accuracy` prints
the accuracy if the provided dataset has a complete `diagnosis` column.

## Technical details

- **Forward/Backward**: hand-written NumPy implementation (no deep learning
  framework), layer by layer ([src/model/layer.py](src/model/layer.py)).
- **Loss**: binary cross-entropy ([src/model/loss.py](src/model/loss.py)).
- **Metrics**: accuracy, precision, recall, f1-score computed every epoch on both
  train and validation ([src/model/metrics.py](src/model/metrics.py)), with the `M`
  (malignant) class treated as the positive class.
- **Early stopping**: training stops automatically if the validation loss doesn't
  improve for `--patience` consecutive epochs; the weights corresponding to the
  best validation loss are restored at the end of training.
- **Normalization**: z-score or min-max, computed on the training set and reapplied
  as-is (same means/stds or min/max) to the validation set and at prediction time.
